# Dicharry's Posture Fix routine (T-spine + pec + scap)

Escalation from the standard [shoulder-warmup](shoulder-warmup.md) when shoulder twinge persists or T-spine stiffness is the upstream limiter.

## The 10-min routine
1. Basketball mobility 2-3 min
2. Travolta peanuts 2-3 min
3. Pec minor stretch 2-3 min per side
4. Overhead carry 3 x 45 s
5. Banded arm circles + band pull-aparts 20 reps each

## Why this works
T-spine stiffness is a common upstream driver of shoulder twinges in runners. Forward-rolled posture from running + sitting all day = tight pec minor + restricted T-spine extension = overhead motion stuff above + impingement.

## Frequency
Daily for 2 weeks when escalating from the standard shoulder-warmup. If still no improvement, see a physio before continuing heavy pressing.
