# Short hill sprints (10-12 sec)

## Purpose
Running economy + leg power. Single highest-return session for running economy specifically, per Barnes et al. (2013) cited by Pfitzinger. Builds calf/Achilles spring without generating high lactate.

## Structure
- 6-10 x 10-12 sec sprint up a 4-8% grade
- Walk-down recovery (60-90 sec)
- Often combined with strides: 6-8 x 10-12 s hills + 8 x 100 m flat strides

## Effort
Near-maximum sprint, but only 10-12 sec -- too short for lactate to spike. RPE 9 during, fully recovered before the next.

## When to use
Base build / aerobic build / marathon build, 1x per week. Drop in race week (or replace with 4 x 8 s only).

## Common mistake
Running them longer than 12 sec (turns it into a metabolic workout, blunts the power adaptation). See short-hill-sprint.md exercise file for full protocol.
