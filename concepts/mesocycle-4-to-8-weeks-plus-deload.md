# Calisthenics mesocycle: 4–8 weeks of build, then 1 week deload

The standard structuring rhythm for calisthenics strength training, per Low. Different from typical running periodisation (3-week build + 1-week recovery) — calisthenics tolerates **longer build phases (up to 8 weeks)** because the rep ranges are lower and connective-tissue stress accumulates slower than running mileage.

## Why 4–8 weeks (not 3 like running)

- Calisthenics linear progression can run for many weeks before plateauing. Don't break a working cycle prematurely.
- Connective tissue is the limiter, not metabolic load. 4–8 weeks of consistent loading gives tendons time to adapt.
- Skill acquisition needs uninterrupted practice. Breaking every 3 weeks interrupts motor learning.

## When to end the cycle

Two valid triggers:
1. **Plateau** — 1 full week without progression on any primary lift. End cycle, take deload.
2. **Time-based** — 8 weeks complete. End cycle regardless. Especially if connective tissue is starting to feel sore or "twingy".

The second trigger is preferred if you're noticing joint/tendon discomfort. **Don't grind through a tendon warning to finish a cycle.**

## What "deload" means

Reduce some combination of:
- Reps per set
- Sets per exercise
- Total exercises (e.g. drop one exercise per category)
- Tempo (slower, controlled)
- Intensity (drop a progression level for one week)
- Frequency (3×/wk → 2×/wk)

The goal: maintain stimulus without accumulating fatigue. A deload week is NOT a no-training week (which would lose adaptation). It's a **lighter** week.

## Sample deload

If standard week is 3 × 8 pull-ups + 3 × 10 dips + 3 × 30 s tuck FL:
- Deload: 2 × 6 pull-ups + 2 × 8 dips + 2 × 20 s tuck FL
- ~50–60 % of normal volume, same exercises, slightly easier reps

## Example cycle layout (off-season calisthenics block)

**Recommended:** 5 weeks build + 1 week deload = 6-week mesocycle.

| Week | Action |
|---|---|
| 1 | Establish baseline. Hit prescribed reps without grinding. |
| 2 | Add 1 rep per set if cycle 1 felt good, or repeat week 1 reps if hard. |
| 3 | Add 1 rep per set; if hit, plan to add a progression for week 4. |
| 4 | Either continue linear (+1 rep) or upgrade one exercise to next level. |
| 5 | Push for max reps at current level. Last hard week. |
| 6 | **DELOAD** — 60 % volume + 2-min walks added daily for active recovery. |

Then start cycle 2 at the new baseline.

## Across multiple mesocycles

3–4 mesocycles per skill (~5 months of work) before a major re-assessment / restructure. After 5 months, evaluate whether to:
- Continue current progression (still hitting goals)
- Upgrade to harder progression and reset to 3 × 5
- Add a new skill / pattern
- Take a longer (2-week) deload if multiple cycles compressed connective tissue

## Active when?

**Primary use: a dedicated calisthenics block**, e.g. the off-season after the A-race. This rhythm structures that block.

During a marathon block, calisthenics is maintenance — no mesocycle structure needed beyond "don't increase load".
