# Skill work when fresh; conditioning when not

Handstand, lever work, muscle-up transitions, and any new-skill acquisition demand a fresh CNS. Push-ups / pull-ups / dips for reps tolerate fatigue. Low's hierarchy:

> Warm-up → Skill work → Strength work → Endurance / metabolic (optional) → Prehab + flexibility

## Why

Skill work requires precise neuromuscular control. Fatigue degrades control before it degrades raw strength → bad reps reinforce bad patterns → see [perfect-practice-beats-practice](perfect-practice-beats-practice.md).

Even within strength work, exercise order matters: each successive set loses ~5 % capacity (CNS bottleneck). By set 15 you're at ~90–95 % peak. **Put your highest-priority goal exercise first.**

## Session ordering

Within a workout:
1. **Skill (handstand, L-sit, lever holds, muscle-up transition practice)** — first, when fresh
2. **Goal strength** (the exercise tied to your primary goal) — second
3. **Compound strength** (pull-ups, dips, push-ups, squat patterns) — third
4. **Accessories / volume work** (isolation, rows for balance, leg patterns) — fourth
5. **Prehab + isolation + flexibility** — last (so primary movers aren't pre-fatigued)

## The handstand exception

Per [handstand-is-the-calisthenics-squat](handstand-is-the-calisthenics-squat.md): wall handstand is the one skill that can be practiced almost daily, low-intensity, because once basic strength is established it becomes primarily a balance/skill movement. Freestanding kick-up attempts to failure are still CNS-expensive.

## When to skip skill work entirely

- Two days post-long-run when legs are still tired (whole-body fatigue)
- Anytime sleep was poor (<6 h)
- After a heavy strength session — skip skill, do volume only
- When mentally distracted / stressed — skill work needs attention; phone-distracted skill work is worse than no skill work

## When skill work *replaces* strength work

A planned light/skill-only day: warm-up + 15–20 min handstand practice + light mobility + done. Total ~30 min. Useful when CNS is fatigued but the body has energy for skill consolidation (the day after a hard run, for instance — legs are tired, shoulders are fine).

## Active when?

ALWAYS. The principle applies both during a marathon block (maintenance sessions still order skill before reps) and in an off-season block where calisthenics is the primary focus.
