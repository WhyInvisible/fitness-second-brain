# Marathon-pace runs inside the long run

Per Pfitzinger, **4 sessions of 8-14 mi (13-22 km) at goal MP across the marathon build** are non-negotiable for *running* a marathon as opposed to finishing one. They integrate endurance + glycogen + pacing + fuelling rehearsal in a single session.

## Why these are the most race-specific stimulus
A standalone long run trains endurance. A standalone MP run trains pacing. The integrated MP-segment long run trains BOTH at race-relevant intensity over race-relevant duration -- the closest you can get to the race without racing it.

## Example progression
A hypothetical four-session progression across the back half of a marathon build, run at the athlete's goal marathon pace (from [goals.md](../goals.md) and [MOC-paces-zones](../MOCs/MOC-paces-zones.md)). Space them roughly every other week and slot them into the [season plan](../plans/season-plan.md).

| Session | Total | MP portion |
|---|---|---|
| 1 | ~24 km long run | ~10 km @ MP |
| 2 | ~28 km long run | ~12 km @ MP |
| 3 | ~30 km long run | ~16 km @ MP |
| 4 | ~32 km long run | ~20 km @ MP |

## Practical execution
- Warm up 4-6 km easy, then settle into MP
- Wear race-day shoes for at least one of these
- Practise race-day fuelling (gels at race intervals)
- The day before: easy or rest. The day after: recovery only.
