# Dicharry's year-round precision workouts (2x/wk anchor)

Per Dicharry, the missing link between "just running" and "barbell strength" is **precision work -- 15-20 min sessions, mostly bodyweight, done 2x per week year-round**.

## What it is
Dynamic warm-ups in disguise. Wire motor patterns, cue glute / foot / T-spine engagement, accumulate to real adaptation over months. **Different from the strength session -- doesn't replace it.**

## The three rotating circuits
1. **Core Circuit** -- donkey toes, pigeon hip extension, frog bridge, tippy twist, bear walk, lateral hurdle hop, burpee
2. **Hip Circuit** -- twisted warrior, butt scoots, glute rainbow, standing hip circles, pigeon hip extension, tippy twist, frog bridge
3. **Band Circuit** -- long-arm band squat, banded hip twist, bear walk, band drive-thru, thread-the-needle plank, foot screws, banded arm circles, band pull-aparts

Rotate one per session.

## When to do it
- Best: before easy runs (works as dynamic warm-up)
- Skip on hard run days
- Drop to 1x/wk in recovery weeks; bump to 3x if running is light
