# Hard days = mobility flows. Easy days = whatever you want.

Don't add a strong vinyasa onto an already-hard day. Mobility on hard days, longer practice on easy days.

## Why
Strong vinyasa (power yoga, hot yoga) is itself a workout -- high HR, real muscular demand. Stacking it onto a hard run or heavy strength session compromises recovery from both.

## Practical splits
- Hard run day -> 20-30 min gentle hip / hamstring flow, no power
- Easy run day -> 30-60 min vinyasa fine
- Rest day -> longest practice if desired
- Long run day -> restorative only, ideally evening
