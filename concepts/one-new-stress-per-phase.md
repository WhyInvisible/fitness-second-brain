# One new training stress per phase

Going from easy -> repetition adds speed only (no aerobic stress). Going from repetition -> interval adds aerobic stress at already-familiar speeds. Going from interval -> threshold adds endurance with no new speed or VO2max demand. Never stack two new stresses.

Per Daniels 2022 Ch. 10.

## Why
Adaptation needs the body to deal with ONE new challenge at a time. Adding two simultaneously means neither gets clean signal, and the recovery cost stacks.

## Daniels' phase progression
1. **B/FIP (Foundation):** easy mileage building
2. **IQ (Initial Quality):** add repetition (R) work -- speed only
3. **TQ (Threshold Quality):** add threshold (T) work -- speed becomes endurance-supported
4. **FQ (Final Quality):** add VO2max (I) work -- full integration

Each phase = one new stress added on top of the already-adapted ones.

## Mapping it onto a season plan
Line the phases of the [season plan](../plans/season-plan.md) up against Daniels' four: a rebuild or base phase = B/FIP, an early base phase with strides and short reps = IQ, an aerobic build = TQ, the marathon-specific build = FQ. If a phase adds two new stresses at once, split it or delay one.
