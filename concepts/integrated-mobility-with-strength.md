# Integrated Mobility: pair mobility with each strength element, between sets

Sommer's signature pedagogical innovation. **Every preparatory and specific element in the GST curriculum has a paired Integrated Mobility (iM) exercise, performed between every working set, targeted at the exact ROM that strength element requires.** Mobility is not a warm-up phase, not a cool-down block, and not a separate session. It is built inseparably into the rest period of the strength work.

## The doctrine

In notation, the strength element `FL/PE1` (Bent Hollow Body Hold) pairs with `FL/PE1>iM` (Cat Cow). You do 1 set of bHBH → 1 set of Cat Cow → rest enough to begin next bHBH set → repeat. The mobility set replaces the empty-rest interval.

The seven Sommer fundamentals each have an iM target:
- **FL > iM** — gymnastics bridge (cat cow → table → shoulder bridge → low bridge → mid bridge)
- **sPL > iM** — medial glute + hip strength (swivel hips → straddle running man → straddle donkey kick → planche hold)
- **SL > iM** — oblique flexibility (standing hip/trunk circles → weighted oblique stretch/reps)
- **MN > iM** — gymnastics pike (stiff leg windmill → Jefferson curl → pike lean → weighted pike hang → vertical pike walk)
- **SLS > iM** — knee mobility + hamstring strength (skiers → twisting squat → shoulder bridge leg curl → natural leg extension)
- **HBP > iM** — shoulder girdle mobility (German arm swing → Xiaopeng forward/backward → arm circles → single arm bent cat)
- **RC > iM** — lat mobility (upright lat lean → bent sideways lat stretch → twisting lat reps → overgrip bent lean)

## Why this works

Sommer's stated reason, paraphrased: across six years of teaching GST to adults, **the most common problem has been a severe mobility deficit, in some cases so extreme it bordered on the pathological** (Sommer, *Mastering Gymnastic Strength Training: Foundation One*, "Integrated Mobility" section).

Adults won't do mobility as a separate block — they perceive it as un-fun, low-value, and skippable. Bolting mobility to the rest period of each strength exercise eliminates the choice. The mobility set IS the recovery. You can't skip it without skipping rest.

Secondary benefit: the iM is *specific to the next set's ROM demand*. Pike work before a manna progression set primes the position. Bridge work between front lever sets primes the shoulder extension and thoracic mobility a clean lever requires.

## Contrast with other doctrines

- **Low (Overcoming Gravity)** puts flexibility / prehab at the END of the workout (Hierarchy block 5), to keep primary movers fresh for strength. Sommer's approach uses lighter mobility doses + targets the specific ROM, so the "primary mover fatigue" concern doesn't apply.
- **Dynamic warm-up doctrine** (most gym culture) puts mobility before strength as a single block. Sommer scatters it through the session.
- **Pavel S&S** has no built-in mobility — relies on the swing + get-up themselves to maintain mobility. Different model entirely.

## How to apply this

For each strength exercise in a calisthenics session, choose one targeted mobility exercise that opens the position you're training. Examples:

| Strength exercise | Sommer-style iM partner |
|---|---|
| Pull-up / ring row | Lat lean stretch (10 r × 30 s between sets) |
| Push-up / dip / ring dip | Shoulder girdle mobility — German arm swing or arm circles (10 r) |
| Squat / pistol | Knee mobility — twisting squat or natural leg extension (5–10 r) |
| L-sit / tuck FL | Pike position — pike lean or Jefferson curl (5 r) |
| Wall handstand | PPT (posterior pelvic tilt) drill — standing or supine (5 r) |
| Plank / planche lean | Medial glute — straddle running man or swivel hips (5–10 r) |
| Back lever / German hang | Bridge — cat cow or shoulder bridge (5 r) |

No need to follow a programming template for the iM — match the number of mobility sets to the number of work sets. The iM dose is what the iM exercise prescribes (typically 5–10 reps or 10–30 s hold).

## Practical application

**During a marathon block:** Optional. Pair pull-up sets with lat-lean stretches; pair push-up sets with arm circles or shoulder girdle work. Low cost, slight upgrade to existing maintenance sessions.

**Off-season / after the A-race:** Adopt iM as the standard structure for every calisthenics set. The doctrine + Sommer's specific PE>iM pairings become the way sessions are organised, not an add-on.

Especially worth integrating: **handstand sets paired with PPT drills + shoulder dislocates**. Wrist work paired with wrist stretches. A handstand-development phase in the off-season benefits the most.
