# Talk test (between strength sets)

Per Pavel Pt II ("Lift No Faster Than You Can Talk"), the talk test is the field rule for **how long to rest between sets** during anti-glycolytic strength work. The rule: rest until you can speak in short sentences before starting the next set. Pavel attributes the test to Oxford mountaineering instructor John Grayson (pre-WWII): "climb no faster than you can talk."

## The rule

> Rest until you can speak in short sentences. Then do the next set.

Calibration sentence options:
- **Pavel's American example**: the Pledge of Allegiance.
- **Outside the US**: a chunk of a song lyric, or the McGill Big 3 cues spoken aloud, or a short technical instruction.
- **Sentence test**: "I am going to do the next set with perfect form" — if you can say it cleanly in one breath, you pass.

If you're not SURE you've passed, the answer is no. Keep resting.

## What failing the test means

Failing the talk test = lactic acid is accumulating faster than the body clears it = anaerobic glycolysis is now dominant. Counterproductive for both poles of S&S:

| Goal | Why failing the test hurts |
|---|---|
| **Power** | CP tanks not refilled → next set relies on glycolysis (1.5–2× weaker per Pavel/Verkhoshansky) → power drops |
| **Endurance** | Lactate flood overwhelms aerobic system → adaptations stop being aerobic-base and become anaerobic-tolerance (a different system) |

## What it does NOT mean

- **NOT "rest until your heart rate is below X bpm".** Pavel deliberately rejects watch-driven rest in favour of breath-driven rest. The breath integrates HR, lactate, perceived effort, and acid clearance — a single high-signal proxy.
- **NOT "rest as long as you want".** If your rest is much longer than the talk test requires, you're slightly over-resting (which mildly costs endurance benefit) — but Pavel's rule is "if in doubt, rest more, not less."
- **NOT a maximum.** Powerful swingers may take 30 minutes to complete 10×10 max-power one-arm swings with full talk-test rests. There is no rep-target rest period.

## How long is "enough"?

It depends. Variables that lengthen the rest:
- More aerobic fitness → recovers faster (shorter rest needed)
- More power per rep → more CP burned (longer rest needed)
- Heavier kettlebell → both above (much longer rest needed)
- Hot day, dehydration, illness, sleep debt (longer rest)
- After a hard running session that day (longer rest — see [anti-glycolytic-training](anti-glycolytic-training.md))

Beginners typically: 60–90 sec between sets.
Owning a 24 kg one-arm swing: 90–120 sec.
Pushing into 32 kg territory: often 2–4 minutes.

## When the rule is relaxed

Pavel's TWO exceptions:

1. **Rest/pause within a set** when grip starts to fail mid-set (e.g. heavy one-arm swing). Park the bell for 10–30 sec, shake the forearm ("shake water off fingertips"), finish the set. This sub-set rest does NOT need to pass the talk test — the goal is just to get enough CP back to finish the 10 reps.
2. **Friday timed-test sessions** (post-Timeless Simple): deliberately compress rest below the talk test, accept the lactate flood, glycolysis breach. ONE day per week. Lighter weight (pavel-simple-sinister "S-" and "G-"). Lessons of [hardstyle-tension-relaxation](hardstyle-tension-relaxation.md) still apply (80% effort, not 100%).

## Connection to the running talk test

The running talk test ("conversational pace") and the strength talk test ARE structurally the same idea — both use the breath as a proxy for the lactate / glycolysis boundary. The difference: running's talk test governs the **work interval** (your easy pace must be conversational); strength's talk test governs the **rest interval** (your next set must wait until conversational return). Both are anchored to Stephen Seiler's lactate-threshold research that [80-20-rule](80-20-rule.md) and [hr-governs-easy-pace-governs-hard](hr-governs-easy-pace-governs-hard.md) draw from.

## Application

For a marathon-training week with already-significant aerobic load, the talk test is the rule that prevents kettlebell training from competing with running. If a swing session leaves the athlete lactate-loaded going into the next run, the running suffers. If the talk test is honoured, the swings finish CP-spent + aerobic-replenished, no lactate hangover, next-day run unaffected.

**Watch + watch + watch out** for the urge to compress rest because "the session is taking too long." 30 minutes is the budgeted time. If 10×10 swings + 5/5 get-ups + warm-up + cool-down takes 40 minutes due to talk-test rests, that's the price of getting it right. If 25 minutes, suspect rest compression and slow down.
