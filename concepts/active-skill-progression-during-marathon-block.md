# Active skill progression during marathon block (the integration framework)

Marathon goal wins, but most non-running disciplines don't actually compete with marathon training when chosen carefully. This is the framework for what to add ACTIVELY (not just maintain) during a marathon build.

## The daily ~20-minute additions (no compromise to running)

These slot into time already spent or replace nothing of value:

| Block | Time | Purpose |
|---|---|---|
| Morning Le Corre breadth: crawl 5 min + beam walk 5 min + 1 get-up variant 2 min | 12 min | Mobility + coordination + corrective; can be done before coffee |
| McGill Big 3 (Russian Pyramid 6/4/2 × 8 s) + cat-camel opener | 10 min | Daily spine hygiene |
| Sommer Standing PPT drill | 30 sec, ad hoc | Alignment habit |
| Crocodile breathing | 2 min | Diaphragm work, before bed or after run |

**Total: ~25 min/day distributed.** None requires a "session" — these are habits.

## Session-day additions (no extra session count)

These go INSIDE existing strength / calisthenics sessions:

### Before any leg day
- **McGill UBF glute reactivation** — 5 min: clam-shell ×15/side (with palpation), glute-only bridge ×10, coin-squeeze ×10. *Mandatory* if the athlete has a hamstring or hamstring-asymmetry history (see [profile.md](../profile.md) → Injuries and niggles): an under-firing glute pushes the hamstring into doing the hip-extension work, a common upstream cause of one-sided hamstring trouble ([glute-amnesia](glute-amnesia.md)).

### Inside existing strength sessions
- **Sommer Integrated Mobility doctrine**: pair a 1-min mobility piece (relevant to the lift) into each rest period. Cost = zero extra time (you were resting anyway). Examples: between RDL sets do a hamstring mobility; between OHP sets do a thoracic extension.

### Before any handstand work
- **Sommer Wrist conditioning WRS/1–4** — 2 min. Prevents the wrist-pain attrition that kills most amateurs' handstand attempts.

### Cossack squat as alternative to Bulgarian split squat
- Sommer's Single-Leg Squat fundamental, level SLS/PE2. Builds adductor mobility + single-leg strength simultaneously. Great option to rotate in.

## Active skill progression targets (work TOWARD, don't just maintain)

| Skill | Active during marathon block | Wait until after the A-race |
|---|---|---|
| **Pull-up volume** | Work toward 15 strict (muscle-up gate) | Muscle-up attempt itself |
| **Dip volume** | Work toward 15 strict (other gate) | Ring dip transition |
| **Handstand** | Sommer Stage 0–4 (wall walks → 60 s chest-to-wall → kick-ups to wall). Daily practice OK per Sommer. | Stage 5 (freestanding 30 s) |
| **L-sit** | Tuck → one-leg → straddle progression | Full L-sit, V-sit, manna progression |
| **Hollow body** | Build to 60 s holds | Foundation for all FSAS work |
| **Arch body** | Build to 60 s holds | Same |
| **False grip familiarisation** | Light volume on rings/bar | Actual muscle-up transition work |

## What stays maintenance-only during marathon block

Skill ladders with high tendon cost or high CNS demand. See [calisthenics-maintenance-in-marathon-block](calisthenics-maintenance-in-marathon-block.md) for the explicit deferred list (front lever, back lever, planche, one-arm chin-up, press handstand, Sommer mastery templates, ring muscle-up work).

## How this scales through the season

Map these rows onto the phases in the [season plan](../plans/season-plan.md):

| Phase | Daily 20-min ritual | Session-day add-ons | Active skill progression |
|---|---|---|---|
| Rebuild / base build | Full | All | All "active" column items |
| Aerobic build | Full | All | Hold current stage, no new attempts |
| Marathon-specific build | Daily ritual only | Glute reactivation always | Maintenance only |
| Tune-up race week | Daily ritual minimum | Glute reactivation only | Hold |
| Peak | Daily ritual minimum | Glute reactivation only | Hold |
| Taper | Daily ritual minimum | Glute reactivation only | Hold |
| Race week | Big 3 + glute reactivation only | — | None |

If part of the season is bodyweight-only (travel, no gym access), it is a good window to push the "active" skill items harder: running volume and gym lifts are lower, so skill work has more of the recovery budget.

## Why this works without compromising marathon goal

1. **Low CNS cost** — handstand wall holds, pull-up volume, L-sit tuck progressions don't draw from the same recovery budget as running.
2. **Zero or minimal extra time** — most additions slot into existing rest periods or replace lower-value work.
3. **Glute reactivation actually IMPROVES running** — a glute that fires on time takes load off the hamstrings and tidies up hip extension in the stride, which matters most for an athlete with a hamstring or asymmetry history.
4. **Le Corre breadth + McGill Big 3 = pure prehab investment** — pays back via fewer niggles, better recovery.
5. **Skill work sets up the post-race block** — arriving at race day with stage-4 handstand + 15 pull-ups + tuck-L-sit fluent means the off-season skill block starts at the muscle-up gate rather than 6 weeks before it.

## When to revert to pure maintenance

- Sleep tanks for >3 days
- HRV / RHR signals indicate accumulated fatigue
- Lower back gets any niggle (drop everything but the Big 3 + walking), especially with a back-injury history
- Running mileage rebuild stalls
- Any new injury

The default during marathon block is "active integration." Revert to pure maintenance is the safety valve, not the baseline.
