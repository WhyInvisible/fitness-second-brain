# Pre-upper-body shoulder warmup (the 5-min routine)

Mandatory before any upper-body session (push, pull, calisthenics skill work). The first-line fix for a shoulder twinge (record any shoulder history in [profile.md](../profile.md) → Injuries and niggles).

## The routine (5 min)
- Band pull-aparts: 2 x 15 (squeeze shoulder blades, slow)
- Wall slides: 2 x 10 (back flat, arms in W -> slide up, wrists/elbows on wall)
- Scapular pull-ups (at bar -- shrug down, no arm bend): 2 x 8
- Banded external rotation: 2 x 12 per side (light band, elbow tucked, rotate hand out)
- Banded arm circles: 20 reps
- Cross-body stretch: 30s each arm
- Sleeper stretch: 30s each side

## What it addresses
- Cold rotator cuff
- Weak scapular stabilisers (lower traps, serratus anterior)
- Forward-rolled shoulder posture (common in runners + lifters)

## Escalation path if twinge persists
1. Two weeks of the 5-min warmup before EVERY upper session
2. If still twinging: switch to [posture-fix-routine](posture-fix-routine.md) (~10 min) for 2 weeks
3. If still twinging: physio
