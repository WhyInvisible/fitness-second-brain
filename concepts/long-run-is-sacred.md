# The long run is sacred

It builds the engine. Don't skip it casually. Don't sabotage it with a hard session the day before.

The long run is the most marathon-specific stimulus available. Time on feet builds glycogen capacity, fat oxidation, mental durability, and leg integrity for marathon distance.

## Scheduling implications
- Long run anchors the week. Everything else flexes around it.
- The day before: easy or rest only.
- The day after: easy or recovery only.

## What "long" means
Builds across the marathon block. A typical shape for an intermediate marathoner (set the athlete's own numbers in the [season plan](../plans/season-plan.md)):
- Base phase: mid-teens km
- Aerobic build: low-to-high 20s km
- Marathon build: up to the low 30s km
- Peak: ~32 km, with a long MP segment inside it -- see [mp-runs-inside-long-run](mp-runs-inside-long-run.md)
