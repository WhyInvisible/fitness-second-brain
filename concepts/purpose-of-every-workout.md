# Purpose of every workout -- answer in one sentence

Every session must answer "what is the purpose of this workout?" in one sentence. If it can't -- substitute easy running.

Per Daniels 2022, this is the single most important coaching question.

## Why
Without a clear purpose, workouts default to "moderately hard for moderately long" -- exactly the medium-hard grey zone that wastes recovery without producing adaptation.

## Corollary
Don't run faster than required to achieve the purpose. Overspeed in an interval session produces fatigue without adaptation.

## Example
- "Why am I doing 6 x 1000 m?" -> "To raise lactate threshold pace."
- "What pace then?" -> "T-pace, not I-pace."
- "What's T-pace?" -> "Whatever the current VDOT table says (see [vdot-system](vdot-system.md) and [MOC-paces-zones](../MOCs/MOC-paces-zones.md))."
- "Could I go faster?" -> "Yes, but that turns this into a VO2max session -- which is on Thursday, not today."
