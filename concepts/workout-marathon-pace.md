# Marathon-pace (MP) run / MP segment in long run

## Purpose
Rehearse race pace, build muscle memory and economy at goal pace. The actual "marathon training" inside the long run. Per Pfitzinger, the most race-specific stimulus a marathoner can do -- integrated training that exercises endurance, glycogen storage, fat utilisation, and pacing discipline in a single session.

## Structure
Chunks of long run at MP, building across the marathon-build phase. An example 4-session progression in the Pfitzinger mould, roughly every other week (place the athlete's own version in the [season plan](../plans/season-plan.md)):
- Session 1: 24 km w/ 10 km @ MP
- Session 2: 28 km w/ 12 km @ MP
- Session 3: 30 km w/ 16 km @ MP
- Session 4: 32 km w/ 20 km @ MP

Warm up 4-6 km easy, then settle into MP.

## Effort
[MP pace](../MOCs/MOC-paces-zones.md) = goal marathon pace (from [goals.md](../goals.md)), RPE 6/10. ~82-88% HRmax / 76-84% HRR.

## When to use
Marathon-specific phase (roughly the ~8 weeks before the taper) inside long runs. ~4 total in the build.

## Surface/course
Road, not track. Mimic the A-race course profile (flat course → flat routes; hilly course → hills).

## Common mistake
Treating MP as threshold. MP is sustainable for the whole race (3–4+ hours for most amateurs) -- if you can't, the pace is too fast for the marathon target.
