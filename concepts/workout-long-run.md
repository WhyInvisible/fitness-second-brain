# Long run

## Purpose
Time on feet, glycogen depletion, fat oxidation, mental durability, leg integrity for marathon distance. The most marathon-specific session.

## Structure
Continuous, easy effort. Optionally with MP segments late in the build phase (see [mp-runs-inside-long-run](mp-runs-inside-long-run.md)).

## Effort
Mostly easy/Z2, RPE 4-5 by the end. If finishing flat-out, too fast.

## Duration
90 min -> 3 hours over the build. Peaks at ~30-34 km in marathon build phase.

## Common mistake
Running too fast, especially early. Discipline the first 30 min. Last hour can include pick-ups but never goes to threshold.

## Fueling
Carry water + gels for anything >90 min. Practice race-day fueling on these.

## Sacred status
See [long-run-is-sacred](long-run-is-sacred.md) for scheduling implications.
