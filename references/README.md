# Literature notes

One note per distilled source (book, paper, coaching plan, course), named `author-slug.md`, written from [../templates/reference.md](../templates/reference.md). The workflow is in [../CLAUDE.md](../CLAUDE.md) → "Distil a source" and [../docs/zettelkasten.md](../docs/zettelkasten.md).

- Put the source files in `resources/` (gitignored, so they never reach GitHub). Run `python scripts/pdf-to-text.py` to extract text.
- A literature note records **the author's claims**, summarised in your words. Your own atomic ideas go in `concepts/`.
- Keep quotes short. These notes are meant to be summaries, which also keeps a shared copy of the repo on the right side of copyright.
- Log each distilled source in [../MOCs/MOC-sources.md](../MOCs/MOC-sources.md).
