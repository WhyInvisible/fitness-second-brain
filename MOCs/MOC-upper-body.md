# Upper-body strength training

> Push/pull programming across a season. Two goals: (1) maintain and modestly grow push-pull strength during a marathon block, (2) build the foundation for calisthenics skill ladders (muscle-up, handstand, L-sit, levers) and climbing-grip work.
>
> Typical starting point: a push day + a pull day built around bodybuilding-style isolation work. This file turns that into a more deliberate progression that supports skill and climbing goals without inflating CNS cost during marathon training.

## Goals by phase

Map these onto the phases in [season plan](../plans/season-plan.md); week counts will differ from plan to plan.

| Phase | Upper-body intent |
|---|---|
| Rebuild | Add compound focus + skill work + climbing intro |
| Base build | Build pull-up volume (gating muscle-up). Progress handstand to chest-to-wall holds. |
| Travel / disrupted block | Maintain via bodyweight — push-ups, dips on bars, pull-ups if access |
| Return → aerobic build | Resume progression. First false-grip work. Hangboard if mounted. |
| Marathon build → peak | Maintenance only. Pull-ups + push-ups + dips for volume. No skill PRs. |
| Taper / race | Very light upper, then nothing |
| Post-race | Dedicated calisthenics block — muscle-up + handstand targeted |

## Movement patterns

| Pattern | Examples | Notes |
|---|---|---|
| Vertical push | Overhead press, pike push-up, handstand | Builds the shoulder structure needed for handstand. |
| Horizontal push | Bench press, push-up, dip | Where most gym-style push work tends to sit. |
| Vertical pull | Pull-up, lat pulldown, muscle-up progressions | The gating capacity for muscle-up — high priority. |
| Horizontal pull | Row (any variant), face pull, sling-row | Prevents shoulder forward roll. Crucial counterbalance to all the pushing. |
| Direct arm | Bicep curl, tricep extension | Useful but secondary. Skip if short on time. |
| Scapular control | Band pull-apart, wall slide, scap pull-up | Lives in [warmups-cooldowns.md](MOC-warmups-cooldowns.md#pre-upper-body-warm-up-5-min--the-shoulder-one) — non-negotiable for shoulder health. |
| Loaded carries | Overhead carry, waiter carry, suitcase carry, farmer carry | **Dicharry's underused weapon for runners.** Build postural strength + anti-lateral-flexion core + grip in one. Bolt onto any push or pull day. |
| Anti-rotation push | Single-leg shoulder press, archer press bridge | Dicharry's runner-specific pushing — trains scap stability + core under asymmetric load. |

## Session templates

### Push day (~45 min including warm-up + skill)

Pre-warm: [shoulder warm-up](MOC-warmups-cooldowns.md#pre-upper-body-warm-up-5-min--the-shoulder-one) (5 min) — **mandatory**.

| Slot | Exercise | Sets × Reps | Notes |
|---|---|---|---|
| A | Vertical push (overhead press BB/DB) | 4 × 5–6 | Heavy. Compound priority. |
| B | Horizontal push (incline bench BB) | 3 × 6–8 | Moderate reps. |
| C | Push-up variant (dip / weighted dip / decline) | 3 × 6–10 | Pick one. |
| D | Light isolation (lat raise OR tricep) | 2 × 12 | Pick one, drop the other to save time. |
| E | Handstand skill | ~10 min | See [calisthenics-skills.md#handstand](MOC-calisthenics-skills.md#handstand-freestanding). Done *after* heavy work but before fatigue is total. |

### Pull day (~45 min including warm-up + skill + grip)

Pre-warm: [shoulder warm-up](MOC-warmups-cooldowns.md#pre-upper-body-warm-up-5-min--the-shoulder-one) (5 min).

| Slot | Exercise | Sets × Reps | Notes |
|---|---|---|---|
| A | Vertical pull (pull-up) | 5 × 5 (or 4 × max-2) | Volume-focused. Building toward 15 strict for muscle-up gate. |
| B | Horizontal pull (one-arm DB row, T-bar, cable row) | 3 × 8 | Compound. Rotate exercise. |
| C | Face pull | 3 × 12–15 | Posterior delt + scap retraction. **Don't skip** — counterbalances all the pushing. |
| D | Bicep work (hammer curl, chin-up) | 2 × 10 | Optional, supports pull-up volume. |
| E | L-sit skill | ~10 min | See [calisthenics-skills.md#l-sit](MOC-calisthenics-skills.md#l-sit). |
| F | Climbing-grip block | ~10 min | See [climbing-grip.md](MOC-climbing-grip.md). Pull day is the right home for grip work — already loaded. |

Post: [elbow cooldown](MOC-warmups-cooldowns.md#post-pull-day-cooldown--elbow--wrist-3-min) — **non-negotiable**.

## Progression rules

- **Pull-up priority.** Until you hit 15 strict pull-ups (the muscle-up gate), prioritise pull-up volume above everything else on pull day. Add reps every week.
- **Compounds before isolation.** Overhead press, bench, pull-up, row first. Lat raises and curls last (or skipped).
- **+2.5 kg per week max** on barbell lifts during rebuild and base build. Plateau? Hold a week, then microload (+1.25 kg via fractional plates or just +1 rep).
- **Skill work before failure work, not after.** Handstand and L-sit need a fresh CNS. Do them between A/B/C compound work and final isolation, not after grinding 5 sets of dips to failure.
- **Volume drops during the marathon build.** Cut all sets by 1 (3 sets → 2). Hold loads. Drop isolation work entirely. The point is to *not lose* strength, not gain.

## Stacking with other systems

- Put push day on a day that follows an easy or light day — e.g. after an easy run with strides — never the day after a quality run.
- Pull day pairs well with a non-running day: it's the longest combined session (pull + L-sit + grip), so give it the lightest running slot of the week.
- **Never schedule a heavy push or pull session within 24 hours of a hard run.** If a hard run gets shifted, the pull day shifts too. Actual days live in [current-week.md](../plans/current-week.md).
- The **elbow cooldown** is the safety valve for adding climbing-grip on top of pull volume. Don't skip it.

## Notes

- This file is the menu + progression. Week-specific loads stay in [current-week.md](../plans/current-week.md).
- When the marathon build starts, prune the templates above — most of the volume drops, and skill work pauses. Re-expand after the A-race.
- If a shoulder twinge persists beyond 2 weeks of consistent [shoulder warm-up](MOC-warmups-cooldowns.md#pre-upper-body-warm-up-5-min--the-shoulder-one) → see a physio before continuing heavy pressing. Before going that route, **try Dicharry's full Posture Fix routine** (basketball mobility → Travolta peanuts → pec minor stretch → overhead carry → banded arm circles + band pull-aparts) daily for 2 weeks. T-spine stiffness is a common upstream driver of shoulder twinges in runners. Record any shoulder history in [profile.md](../profile.md) → Injuries and niggles.
