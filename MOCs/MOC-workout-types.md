# MOC — Workout types

> Atomic workout types in [concepts/](../concepts/). Each is one note. This MOC groups them by intensity / purpose.
>
> Actual pace / HR targets live in [MOC-paces-zones.md](MOC-paces-zones.md). This file is the *what* and *why*. Pace targets are the *how fast*.

## Recovery + easy

- [Recovery jog](../concepts/workout-recovery-jog.md) — active recovery, not training
- [Easy run](../concepts/workout-easy-run.md) — Z2 / conversational, the bedrock

## Long + race-specific

- [Long run](../concepts/workout-long-run.md) — time on feet, the marathon-specific stimulus
- [Marathon-pace run](../concepts/workout-marathon-pace.md) — MP segment inside long run, Pfitz's 4-session progression
- [Progression run](../concepts/workout-progression-run.md) — easy → MP across the run

## Threshold

- [Sub-threshold (LT1)](../concepts/workout-sub-threshold-lt1.md) — Norwegian workhorse, 2x/wk
- [Threshold (LT2 / Daniels T)](../concepts/workout-threshold-lt2.md) — Norwegian + Pfitz + Daniels variants

## VO2max + speed

- [VO2max intervals (Daniels I)](../concepts/workout-vo2max-intervals.md) — 2-6 min reps, 5K pace
- [Repetition (Daniels R)](../concepts/workout-repetition.md) — speed work at mile pace
- [Strides](../concepts/workout-strides.md) — neuromuscular, 6-8 x 15-20 sec, 2x/wk

## Variety + power

- [Fartlek](../concepts/workout-fartlek.md) — unstructured speed play
- [Hill repeats (long Z4)](../concepts/workout-hill-repeats-long.md) — 60-90 sec or 20x200m Norwegian style
- [Short hill sprints](../concepts/workout-short-hill-sprints.md) — 10-12 sec, economy + power

## Weekly mix (typical marathon-build week, Norwegian-influenced)

| Sessions | Type | Day |
|---|---|---|
| 1 | Long run (often with MP late) | Saturday |
| 2 | Sub-threshold (LT1) | Tue + Thu |
| 1 | Threshold (LT2) OR hill repeats | Alternating weeks |
| 1 | Strides woven into an easy run | Any easy day |
| 1-2 | Easy runs | Remaining days |

**Never two hard sessions back-to-back.** See [sequence-by-recovery-cost](../concepts/sequence-by-recovery-cost.md).

## Skip in base period

- Don't run Zone 3 long intervals during base — see [skip-zone-3-long-intervals](../concepts/skip-zone-3-long-intervals.md).
- VO2max work in base is too early (Daniels) — see [one-new-stress-per-phase](../concepts/one-new-stress-per-phase.md).

## Per-zone weekly volume caps

Per Daniels:
- **T-pace**: ≤ 10% of weekly mileage in one session
- **I-pace**: ≤ 8% of weekly mileage OR 10K, whichever is less
- **R-pace**: ≤ 5% of weekly mileage OR 5 mi (8 km), whichever is less

See [per-zone-weekly-volume-caps](../concepts/per-zone-weekly-volume-caps.md).

## How sessions appear in week plans
