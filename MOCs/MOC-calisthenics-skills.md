# Calisthenics skill ladders

> Progressions for five common calisthenics skills. Each ladder lists the steps from a typical starting point to the skill itself; start the athlete at the stage their current numbers in [profile.md](../profile.md) support. **Don't skip steps** — tendons adapt slower than muscle, and skipping is how shoulders and elbows get angry.

For each skill, the rule is: hit the prescribed reps / hold time cleanly for **2 consecutive sessions** before advancing.

## Handstand (freestanding)

End goal: 10-second freestanding handstand.

| Stage | Drill | Target before advancing |
|---|---|---|
| 0 | Pike push-ups | 3 × 8 with elevated feet |
| 1 | Wall walks (chest-to-wall) | 3 × 1, hold 5–10s at top |
| 2 | Chest-to-wall handstand hold | 3 × 30s |
| 3 | Back-to-wall handstand hold (hips over shoulders) | 3 × 30s |
| 4 | Kick-up to wall (chest-to-wall) | Consistent kick-up, 10/10 attempts |
| 5 | Freestanding kick-ups (away from wall) | 5s holds, 3 × 5 attempts |
| 6 | Freestanding handstand | 10s hold |

Frequency: 2× per week, 10 min at end of upper push day. Skill work needs a fresh CNS — do it before pull-ups-to-failure type work, not after.

## L-sit

End goal: 20-second L-sit on parallettes.

| Stage | Drill | Target before advancing |
|---|---|---|
| 0 | Hollow body hold | 3 × 30s |
| 1 | Tuck L-sit (knees tucked) | 3 × 20s |
| 2 | One-leg L-sit (alternating) | 3 × 15s per leg |
| 3 | Straddle L-sit | 3 × 15s |
| 4 | Full L-sit | 3 × 10s → 3 × 20s |

Add compression work: seated, legs straight in front, lift heels off floor — 3 × 10. This is the missing piece most people skip.

Frequency: 2× per week, 10 min at end of upper pull day.

## Muscle-up (bar)

End goal: clean strict bar muscle-up.

Prerequisites first: 15 strict pull-ups, 15 dips. For most athletes pull-up volume is the gating factor; check the current numbers in [profile.md](../profile.md).

| Stage | Drill | Target before advancing |
|---|---|---|
| 0 | Pull-up volume | 15 strict pull-ups (any rep scheme: 5×5 → 5×6 → 3×8 → max set 15) |
| 1 | Explosive pull-ups (chest to bar) | 3 × 5 with chest hitting the bar |
| 2 | High pull-ups (sternum to bar) | 3 × 3 |
| 3 | False-grip pull-ups | 3 × 5 (false grip = wrist over the bar) |
| 4 | False-grip pull-up + transition (slow eccentric from top) | 3 × 3 |
| 5 | Banded muscle-up | 3 × 3 |
| 6 | Strict bar muscle-up | 1 clean rep |

Frequency: Stage 0 is just pulling volume — bake into pull day. Stages 1–6: 1× per week, on a fresh day, ~15 min.

**Pause this ladder during the marathon-specific build.** Resume after the A-race.

## Front lever

End goal: clean tuck front lever → straddle → full (long arc, 6+ months).

| Stage | Drill | Target before advancing |
|---|---|---|
| 0 | Hollow body + arch body holds | 3 × 30s each |
| 1 | Tuck front lever (knees tucked tight, hips at shoulder height) | 3 × 10s |
| 2 | Advanced tuck (back flat, knees away from chest) | 3 × 15s |
| 3 | Straddle front lever | 3 × 5s → 3 × 15s |
| 4 | Full front lever | 3 × 5s+ |

Frequency: 1× per week max — high CNS + connective tissue cost. **Definitely paused** during a marathon build.

## One-arm hang → one-arm pull-up (very long arc)

End goal: 1-arm dead hang for 30s (precursor to one-arm pull-up; the full one-arm pull-up is years of work).

| Stage | Drill | Target before advancing |
|---|---|---|
| 0 | Two-arm dead hang | 3 × 60s |
| 1 | One-arm assisted hang (other hand grips wrist) | 3 × 30s per side |
| 2 | One-arm assisted hang (other hand on towel / lower bar) | 3 × 20s per side |
| 3 | One-arm dead hang | 3 × 10s → 3 × 30s per side |

Grip + elbow tendons take *months* to adapt. Don't rush. Frequency: 1× per week, 10 min.

## How to use these during the season

Map these phases onto the dates in [season plan](../plans/season-plan.md). If the A-goal is a marathon, the marathon wins any conflict (see [a-goal-wins-conflicts](../concepts/a-goal-wins-conflicts.md)).

| Phase | Active skills | Frequency |
|---|---|---|
| Rebuild / early base | Handstand stages 0–1, L-sit stages 0–1, muscle-up stage 0 (pull-up volume) | 2 sessions/wk, 10 min each |
| Base build | Handstand 2–3, L-sit 2, muscle-up 0–1, front lever 0, one-arm hang 0 | 2 sessions/wk, ~15 min each |
| Travel / no-equipment stretch | Maintain wherever you got to. Pike push-ups, tuck L-sit, hollow holds — no bar needed. | When time allows |
| Return / aerobic build | Resume previous progression | 2 sessions/wk |
| Marathon-specific build → race | **Maintenance only** — pull-ups, push-ups, dips for volume. No new skill work. See [calisthenics-maintenance-in-marathon-block](../concepts/calisthenics-maintenance-in-marathon-block.md). | Woven into existing sessions |
| Off-season after the A-race | Dedicated block. Pick one or two skills (e.g. muscle-up + freestanding handstand) as the targets. | 3–4 sessions/wk |

## What to log for skill work

Lightweight in the training log — just the stage + reps/time achieved. e.g.:

```
- Handstand: stage 2 — 3 × 30s chest-to-wall, felt solid
- L-sit: stage 1 — 3 × 18s, 3rd set dropped early
```

This is how we know when to advance.
