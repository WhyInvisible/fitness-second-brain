# Lower-body strength training (general)

> The full menu and programming reference for lower-body work, beyond the marathon-specific lens. **[running-strength.md](MOC-running-strength.md) is the active prescription during marathon season** — this file is broader: exercises, movement patterns, programming templates for non-marathon contexts.
>
> Comes alive in the off-season after the A-race (e.g. a calisthenics + strength block), and serves as a reference menu when designing marathon-season strength work.

## When to use which file

| Context | Use |
|---|---|
| Marathon training (build → race) | [running-strength.md](MOC-running-strength.md) — phased, marathon-supporting, moderate loads, no PRs |
| Off-season strength block (after the A-race) | This file — heavier loads, PR pursuit, hypertrophy options |
| Future cycles | This file as reference; design new phased plan as needed |
| Exercise menu / form cues | This file (comprehensive) |

## Hard rules (carry over from running-strength.md, always apply)

- **Check [profile.md](../profile.md) → Injuries and niggles first.** If the athlete has back-injury history, it shapes everything: form first, linear progression, trap-bar before conventional deadlift, possibly forever (see [MOC-injuries-management](MOC-injuries-management.md)).
- **Pre-warm with the [pre-leg-day warm-up](MOC-warmups-cooldowns.md).** Glute activation matters ([glute-amnesia](../concepts/glute-amnesia.md)).
- **Watch any left/right asymmetry** (e.g. a tighter hamstring on one side). Favour single-leg work to address imbalance.
- **Stop if back complains.** Sub yoga / mobility.
- **Respect your alignment — assess, don't guess.** Per Dicharry (Ch 8): some bodies have hip / shin rotational torsion that means "knees over second toe" is anatomically wrong for them. Run Craig's test before adopting a universal cue — worth doing before loading heavy squats. For some athletes, feet turned out (11 and 1 o'clock) is the correct stance. See [individual-alignment-assessment](../concepts/individual-alignment-assessment.md).
- **Bar speed never drops > 50% within a set.** Set ends when it does. Never grind. Never to failure. (Dicharry.)

## Movement patterns + exercise menu

### Squat patterns
| Exercise | Use | Notes |
|---|---|---|
| Goblet squat | Beginner / rehab / warm-up | Easy on the back. Good ROM teacher. |
| Front squat | Strength + posture | Lower-back-friendlier than back squat for most. |
| Back squat | Strength + leg mass | Loads back more — watch for cumulative fatigue. |
| Box squat | Power / control | Pause at depth, drives explosive concentric. |
| Pause squat | Strength + control | 2–3 s pause at bottom. Brutal but bulletproofs depth. |
| Bulgarian split squat | Unilateral, glute + quad | Excellent for runners. Hits asymmetries. |
| Pistol squat | Calisthenics goal | Progressions: box-assisted → counterweight → full. |
| Wall sit | Isometric quad endurance | Cheap, no equipment. |

### Hinge patterns
| Exercise | Use | Notes |
|---|---|---|
| DB Romanian deadlift | Rehab, light hinge | Phase 1 entry point. Light, slow, perfect form. |
| Chair-of-death squat | Form prerequisite | Dowel against spine + chair to limit knees. Dicharry: master before loading. |
| Single-leg deadlift with dowel | Form prerequisite + asymmetry | Dicharry's #1 most-trained pattern. Master unloaded before any loaded SL hinge. |
| Barbell RDL | Hamstring + glute + back | The main hinge progression. Dicharry target: 1.5–1.8× BW for 8 reps. |
| Landmine single-leg deadlift | Loaded SL hinge | Bar anchored in corner; safer than free DB or barbell SL-RDL. Dicharry uses in every loaded hinge workout. |
| Trap-bar deadlift | **Primary heavy hinge with back history** | Less shear on the back than conventional deadlift. |
| Conventional deadlift | Strength PR pursuit | **With back history, defer until the off-season at least**; reintroduce slowly if at all. |
| Sumo deadlift | Hip-dominant variant | Wider stance, more glute, less lower-back demand than conventional. |
| Single-leg RDL | Unilateral hinge + balance | Excellent for a left/right hamstring asymmetry. |
| Good morning | Posterior chain strength | Light only. Cumulatively spicy on the back. |
| Hip thrust | Glute isolation | Heavy possible, very back-friendly. Dicharry target: 2× BW for 6 reps. |
| Kettlebell swing | Power + posterior endurance | Hip hinge with momentum. Light KB to start. Dicharry uses in every performance workout. |
| Kneeling banded deadlift | Pre-run wiring | Hip-thrust pattern, no spinal load. Excellent warm-up. |
| Band drive-thru | Running-specific power | Single-leg + opposite-knee-drive = the running stride pattern. |

### Lunge + step patterns
| Exercise | Use | Notes |
|---|---|---|
| Walking lunge | Endurance + hip | Add DBs for load. |
| Reverse lunge | Quad + glute, knee-friendly | Often easier on knees than forward lunge. |
| Step-up (bench/box) | Unilateral leg drive | Loaded with DBs. Great for runners. |
| Lateral lunge | Frontal plane, adductor | Often missed. Hits planes runners don't naturally train. |
| Curtsy lunge | Glute med | Helps hip stability for running. |
| Cossack squat | Mobility + strength | Deep lateral squat — opens up adductors. |

### Single-leg / balance
| Exercise | Use | Notes |
|---|---|---|
| Single-leg balance | Foundation | Close eyes for harder. 30s per leg minimum. |
| Single-leg deadlift | Hinge + balance + asymmetry | DB in opposite hand. |
| Skater squat | Single-leg quad + glute | Knee-friendly. Counterbalance with light weight in hands. |
| Lateral step-down | Knee / VMO | Step off a box, slowly tap heel down, drive back up. |
| Shrimp squat | Advanced single-leg | Calisthenics progression toward true SL strength. |

### Calf / lower leg
| Exercise | Use | Notes |
|---|---|---|
| Single-leg calf raise | Foundational | Off a step, full ROM, slow eccentric. Always single-leg, not double. |
| Standing calf raise (loaded) | Hypertrophy + strength | Machine, smith, or DB in hand. |
| Seated calf raise | Soleus focus (vs gastroc) | Bent-knee position isolates soleus, which is heavily used in distance running. |
| Tibialis raise | Anterior shin (anti-shin-splint) | Toes-up against a wall, raise. Often ignored, very useful for runners. |
| Calf eccentric drop | Achilles health | Slow lower from raised position. Tendon prehab. |

### Glute-specific
| Exercise | Use | Notes |
|---|---|---|
| Glute bridge | Activation + strength | BW or loaded. Squeeze at top. |
| Hip thrust | Heavy glute work | Back on bench, barbell on hips. |
| Single-leg glute bridge | Unilateral | Address right/left asymmetry. |
| Banded clamshell | Glute med activation | Side-lying. Boring but effective for hip stability. |
| Banded lateral walk | Glute med + hip | Excellent warm-up too. |
| Cable kickback | Glute isolation | Low priority, but option. |

### Posterior chain (overlap with hinge)
| Exercise | Use | Notes |
|---|---|---|
| Back extension | Lower back endurance | Hyperextension bench. Don't go past neutral. |
| Reverse hyper | Spinal decompression + glute | If gym has one — excellent for back health. |
| Hamstring curl (machine) | Knee flexion strength | Underrated for runners. |
| Nordic curl | Eccentric hamstring | Advanced. Start with assisted (band). |

## Programming templates

### Template A — Strength block (5/3/1 style, post-marathon)

4-week block, 1 main lift per session, ~3 sessions per week. Best for: dedicated strength gains, an off-season rebuild block.

```
Week 1: 5 × 65%, 5 × 75%, 5+ × 85%
Week 2: 3 × 70%, 3 × 80%, 3+ × 90%
Week 3: 5 × 75%, 3 × 85%, 1+ × 95%
Week 4 (deload): 5 × 40%, 5 × 50%, 5 × 60%
```

Cycle main lifts: front squat, trap-bar deadlift, overhead press (handled in upper-body). Assistance work: split squat, RDL, single-leg work, calves.

### Template B — Hypertrophy block (post-marathon mass gain)

Higher volume, moderate loads. Best for: putting on muscle when running is light.

- 3 sessions/week, ~8–12 reps, 4 sets per main exercise
- Compound first, isolation second
- E.g. front squat 4×8, RDL 4×8, Bulgarian split squat 3×10/leg, leg curl 3×12, calf raise 4×12

### Template C — Maintenance (this is what [running-strength.md](MOC-running-strength.md) Phase 5 does)

1 session/week, 3×5 on main lifts at ~80% of recent best, never to failure. Holds strength without spending CNS. Already prescribed for marathon-build phase.

### Template D — Calisthenics-supportive (off-season block)

Focused on supporting pistol squat + general body control. Less heavy barbell, more single-leg strength + mobility.

- Pistol progressions (3 × 5/leg)
- Bulgarian split squat (3 × 8/leg)
- Single-leg RDL (3 × 8/leg)
- Cossack squat or shrimp squat (3 × 6/leg)
- Calf + tib work (3 × 12)
- Hip mobility flow

## Off-season roadmap (template)

After the A-race, a dedicated calisthenics + strength block is a common choice. Lower-body priorities will likely be:

1. **Reintroduce heavier squat work** — pursue PRs cautiously, with trap-bar deadlift as the primary hinge if there's back history.
2. **Pistol squat progression** — the calisthenics gap; works hand in hand with single-leg strength.
3. **Hypertrophy block possibility** — if comfortable, the off-season is when to put on a little muscle.
4. **Conventional deadlift reintroduction (maybe)** — only if everything's good, ideally with a coach, light weights, slow build (see [return-to-sport-progression-after-back-injury](../concepts/return-to-sport-progression-after-back-injury.md)).

Flesh this out in the last few weeks before the A-race, when planning the post-race period in the [season plan](../plans/season-plan.md).
